# Pixel 8a 完整数据集识别精度

[English](<README.md>)

两个图像配置均在 Pixel 8a（Android API 37、ARM64、ONNX Runtime 1.29.0、CPU 4 线程）上完成全部图像及类别文本的特征计算。
每模型覆盖 CIFAR-100 test 2,000 张和 Imagenette val 3,925 张，共 5,925 张；类别文本分别为 100 条和 10 条。特征拉回主机后按原协议 L2 归一化、计算余弦排序和指标。没有用主机特征替代手机结果。

## 手机准确率

| 数据集 | 图像配置 | Top1 | Top5 | 类别查询 P@10 | 类别查询 mAP |
|---|---|---:|---:|---:|---:|
| cifar100 | FP32 图像 + 动态 INT8 文本 | 74.60% | 93.95% | 85.10% | 75.81% |
| cifar100 | 混合 INT8 图像 + 同一动态 INT8 文本 | 73.90% | 93.10% | 84.80% | 74.37% |
| imagenette | FP32 图像 + 动态 INT8 文本 | 98.04% | 99.87% | 100.00% | 99.30% |
| imagenette | 混合 INT8 图像 + 同一动态 INT8 文本 | 97.96% | 99.85% | 100.00% | 99.25% |

两配置共用同一动态 INT8 文本模型和预处理输入，两个数据集的导出文本特征均逐字节一致。混合 INT8 图像配置保留敏感 Conv 的 FP32 计算。P@10/mAP 是类别文本对完整图片集合的检索指标，按类别平均，不是图片与自由描述配对的 Recall@K。

## 手机 FP32 与混合 INT8 的差值

差值为混合 INT8 − FP32，单位百分点（pp）。对相同图片做 2,000 次成对 bootstrap（seed 20260913）；95% CI 仅描述当前数据分布。

| 数据集 | Top1 差值 pp | 95% CI pp | FP32 独对 / INT8 独对 | 预测翻转数 |
|---|---:|---:|---:|---:|
| cifar100 | -0.70 | [-1.80, +0.30] | 65 / 51 | 192 |
| imagenette | -0.08 | [-0.31, +0.15] | 12 / 9 | 26 |

## 同一模型：主机与手机

主机环境：Linux-6.6.87.2-microsoft-standard-WSL2-x86_64-with-glibc2.39；同用 ONNX Runtime 1.29.0、4 线程及相同模型/图片/类别文本。下表差值为手机 − 主机，逐图翻转记录包含样本 ID、真值和两端预测。

| 数据集 | 配置 | 主机 / 手机 Top1 | Top1 差值 pp | 配对 95% CI pp | 预测翻转数 / 比例 |
|---|---|---:|---:|---:|---:|
| cifar100 | FP32 图像 + 动态 INT8 文本 | 75.30% / 74.60% | -0.70 | [-1.25, -0.15] | 51 / 2.55% |
| cifar100 | 混合 INT8 图像 + 同一动态 INT8 文本 | 73.60% / 73.90% | +0.30 | [-0.50, +1.10] | 119 / 5.95% |
| imagenette | FP32 图像 + 动态 INT8 文本 | 98.11% / 98.04% | -0.08 | [-0.20, +0.03] | 8 / 0.20% |
| imagenette | 混合 INT8 图像 + 同一动态 INT8 文本 | 98.06% / 97.96% | -0.10 | [-0.33, +0.13] | 24 / 0.61% |

Top5、P@10、mAP 的跨平台差值及逐图翻转明细同时保存在 JSON 中。预测翻转可能纠错，也可能由对变错或两端都错；向量余弦相似度不能代替有真值的准确率。

此前同一混合模型的主机/手机首图 cosine 最低为 0.98734200，未达到该检查的 0.9999 阈值。
这确认了跨平台数值差异，尚不能单凭首向量断定识别质量失败或定位具体内核原因；本报告使用手机完整数据集结果直接度量其实际影响。

## 验证与范围

模型文件、导出 manifest、评测样本清单与主机结果通过 SHA256 关联；手机记录的实际模型/输入哈希与清单一致，拉取的八个特征文件重新校验字节数、形状和 SHA256，全部特征检查有限且非零。文本输入哈希由相同类别提示词重新生成，共享文本输出哈希逐字节一致。
原始主机图像与 token 输入文件也已顺序重算 SHA256。
固定英文单模板 `a photo of a {class}`，未在评测集校准、调参或选择提示词。CIFAR 原图为 32×32，Imagenette 为 10 类子集；结果不覆盖真实相册、中文查询、OCR 或自由描述检索。
这是单次完整特征导出的准确率验证。导出过程的读写、校验与执行总时长不作为推理速度数据；短时 benchmark 的预热后 P50/P95 仍单独报告，不能混合计算。

原始 .f32 特征数组与大型模型、输入文件在本地生成，不纳入 Git。归档 JSON 保留测量值、逐图预测、配对统计和哈希。新克隆可审计这些记录；重新计算完整余弦排序须先在手机重新生成特征文件。
