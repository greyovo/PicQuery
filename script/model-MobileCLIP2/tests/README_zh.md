# 离线报告检查

[English](README.md)

在仓库根目录，使用现有 MobileCLIP 评测 Python 环境运行：

```sh
python -m unittest discover -s script/model-MobileCLIP2/tests -p 'test_*.py' -v
```

所有测试均不执行模型、不操作手机、不下载数据。报告与评估器回归使用归档标签和小型临时假模型文件，并在本地生成合成特征；检查错误哈希、样本映射、不完整运行、无效向量、不同运行库/线程数、损坏指标和双语数值漂移。临时报告明确标注为合成数据，每次测试后删除。

`test_report_archive.py` 将公开的中英表格与归档指标对齐，从逐图预测与标签重算 Top1，核对成对计数和区间、重算时延分位数，验证手机报告哈希链和相同的文本输出哈希。本地存在原始 `.f32` 时，还会重算其哈希并比较文本字节；否则该单项测试明确跳过。重新计算完整排序仍需生成特征数组并运行评估器。

使用[模型说明](../README_zh.md)已列出的依赖即可。测试不新增依赖，不需要 Git 忽略的模型二进制或多 GB 输入张量，但需要归档 JSON。新实验输出请放在 `build/`，避免覆盖已发布的测量数据。
