The v1 files are official-checkpoint re-exports, not the missing original App MobileCLIP ORT pair. The mixed INT8 image candidate retains sensitive operators in FP32 and does not automatically replace the App's FP32 image model. Full FP32 text references, intermediate/failed quantization candidates, datasets and generated embeddings are excluded.

Each ZIP contains root-level model files, English/Chinese README files and an internal `SHA256SUMS`. [SHA256SUMS](SHA256SUMS) in this directory checks the **ZIP files**; [manifest.json](manifest.json) records each model's bytes, SHA-256, precision and destination. ZIP compression changes size, not model bytes.

## Verify and install the App models

To build the current App, only the App bundle is required; the other three bundles are for comparisons. Open the [Google Drive folder](https://drive.google.com/drive/folders/1eWHZ08c7TmVJU9ReQAe7z8o-EE9R297g?usp=sharing) and download the original `picquery-mobileclip2-app-20260913.zip` into `build/model-downloads/` (create the directory if needed). Download that file individually: a new ZIP generated by Drive's folder-download feature has a different checksum. Run the following commands from the repository root.

1. Verify the archive against this repository's ZIP checksum list. In PowerShell:

   ```powershell
   $archiveName = 'picquery-mobileclip2-app-20260913.zip'
   $archivePath = Join-Path 'build/model-downloads' $archiveName
   $checksumLines = @(Get-Content 'script/model-MobileCLIP2/downloads/SHA256SUMS' | Where-Object { $_.EndsWith("  $archiveName") })
   if ($checksumLines.Count -ne 1) { throw 'Expected one pinned ZIP checksum' }
   $expected = ($checksumLines[0] -split '  ', 2)[0]
   if ((Get-FileHash -LiteralPath $archivePath -Algorithm SHA256).Hash -ne $expected) { throw 'ZIP SHA-256 mismatch' }
   ```

   On Linux, run `sha256sum --ignore-missing -c ../../script/model-MobileCLIP2/downloads/SHA256SUMS` from `build/model-downloads/`. At least the App ZIP must report `OK`.

2. Extract to a staging directory, not over the repository root:

   ```powershell
   Expand-Archive -LiteralPath $archivePath -DestinationPath 'build/model-downloads/extracted-app'
   ```

   Use a fresh staging directory when repeating this step. On Linux, `unzip build/model-downloads/picquery-mobileclip2-app-20260913.zip -d build/model-downloads/extracted-app` performs the same extraction.

3. Copy only these four model files into `app/src/main/assets/`:

   ```powershell
   $modelNames = @('mobileclip2_s0_image.onnx', 'mobileclip2_s0_text_int8.onnx', 'image_model.tflite', 'text_model_dynamic_wi8.tflite')
   foreach ($name in $modelNames) {
       Copy-Item -LiteralPath (Join-Path 'build/model-downloads/extracted-app' $name) -Destination (Join-Path 'app/src/main/assets' $name)
   }
   ```

   On Linux, use `cp build/model-downloads/extracted-app/*.onnx build/model-downloads/extracted-app/*.tflite app/src/main/assets/`. Retain `bpe_vocab_gz`, `mlkit/` and tracked metadata/config files. Do not rename the offline `text_model.tflite` reference to the dynamic INT8 filename.

4. Build using the [Android instructions](../README.md#run-on-android). Installing only an ONNX or TFLite pair supports its corresponding flavor; building both requires all four files.

Packaging these files does not constitute a new accuracy or timing measurement.

## Publication and CI

For CI, verify the original ZIP can be downloaded without signing in and that its bytes match the pinned checksum. The shared folder is a manual download entry point; do not assign its URL to CI's `MODELS_URL`. A sharing/preview page or HTML download-confirmation response is not a direct model ZIP URL. CI needs an unauthenticated download that returns ZIP bytes and a matching archive SHA-256. Individual ZIP download URLs remain unset in [manifest.json](manifest.json) until verified.

Keep published bundles immutable; changed model bytes require a new bundle and checksum. Model assets retain their upstream terms: [Apple model license](https://github.com/apple-aiml-research/ml-mobileclip/blob/main/LICENSE_MODELS) and [OpenAI CLIP license](https://github.com/openai/CLIP/blob/main/LICENSE).
